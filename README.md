# ObahNow - Mendigitalkan Usaha dari Desa ke Kota

Website perusahaan digital yang membantu UMKM dan perusahaan untuk berkembang di era digital.

## Fitur

- 🏢 **Company Profile** - Website profesional untuk perusahaan
- 🛒 **Usaha Kampung** - Landing page khusus untuk UMKM
- 🔧 **Maintenance & Support** - Dukungan teknis berkelanjutan

## Teknologi

- Next.js 16.1.6 dengan App Router
- TypeScript
- Tailwind CSS v4
- Responsive Design

## Memulai

Pertama, install dependencies:

```bash
npm install
```

Kemudian, jalankan development server:

```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser Anda.

## Build Production

Untuk membuat production build:

```bash
npm run build
npm start
```
